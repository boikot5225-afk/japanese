# Japanese

Полноценный русскоязычный самоучитель японского языка для Android.

## Цель

Создать offline-first приложение, которое ведёт пользователя от нуля до самостоятельного чтения и подготовки к JLPT. Это не каталог карточек, а последовательный курс:

- хирагана и катакана;
- грамматика;
- лексика;
- кандзи;
- спряжения;
- аудирование;
- чтение;
- письмо;
- интервальное повторение;
- подробная проверка открытых ответов.

## Первый вертикальный срез

Первая версия должна полностью провести один урок:

1. краткое объяснение;
2. новые слова;
3. примеры;
4. несколько типов упражнений;
5. итоговая проверка;
6. запись прогресса и назначение повторения.

## Технологии

- React Native + Expo
- TypeScript
- локальные JSON-данные на первом этапе
- SQLite для прогресса и контента после стабилизации моделей
- Android как основная платформа

## Архитектура

```text
src/
├── content/       учебные данные
├── domain/        модели языка и курса
├── engine/        проверка ответов и тренировочные сессии
├── screens/       экраны приложения
└── theme/         визуальная система
```

## Принцип

Одна грамматическая конструкция может проверяться через выбор, ввод, сборку предложения, аудирование и исправление ошибки. Прогресс хранится отдельно для узнавания, воспроизведения, чтения, аудирования, письма и употребления.
