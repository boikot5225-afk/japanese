- вопросы на чтение кандзи больше не показывают чтение в скобках;
- письмо по памяти больше не показывает сам кандзи ни в вопросе, ни в заголовке;
- заголовок повторения соответствует фактически проверяемому знанию;
- удалена повторяющаяся инструкция внутри поля письма;
- Android-экран защищён от наложения на строку состояния;
- принимаются естественные варианты с に вместо へ, без は после 昨日 и с кана вместо изученного кандзи;
- добавлены регрессионные тесты против утечки ответа в формулировке задания.
